# Customer Churn Analysis Dashboard

## 📌 Project Overview
This project analyzes customer churn behavior using Python and Power BI. The goal is to identify key factors that influence customer churn and present insights through an interactive dashboard.

---

## 🎯 Objectives
- Understand customer churn patterns
- Identify key drivers of churn
- Build an interactive dashboard for decision-making

---

## 🛠 Tools Used
- Python (pandas, seaborn, matplotlib)
- Power BI
- Jupyter Notebook

---

## 📊 Dashboard Features
- KPI metrics (Total Customers, Churn Rate, Average Age, Average Balance)
- Churn analysis by:
  - Geography
  - Activity Status
  - Number of Products
  - Gender
- Customer profile insights:
  - Average Balance
  - Average Satisfaction
  - Average Age

---

## 🧠 Key Insights
- Inactive customers are more likely to churn
- Customers with fewer products tend to leave more
- Lower satisfaction is associated with higher churn
- Older customers show slightly higher churn behavior

---

## 📈 Outcome
This project demonstrates skills in data cleaning, exploratory data analysis, and dashboard development using Power BI.
